# Gemini AI Skills for Oracle CPQ Integration

This repository contains custom Google Gemini AI skill definitions and integration scripts designed to automate, analyze, and enhance Oracle CPQ development workflows.

## Features
- **BML Scripting & BMQL Automation:** Pre-built prompts and skill contexts to generate valid BML code, loop structures, and array manipulations.
- **REST API Integration Bridge:** Scripts connecting Gemini API endpoints with Oracle CPQ Commerce and Configuration REST APIs.
- **Asset-Based Ordering (ABO) Logic Checks:** Automated verification routines for telecom/subscription model structures.
